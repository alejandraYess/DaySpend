# DaySpend

Aplicación web para registrar gastos personales, verlos por periodo y categorías y consultar un resumen sencillo del dinero gastado. Frontend con React, TypeScript, Tailwind y Vite en la carpeta `client`. Documentación del curso y del producto en `docs/`.

## Tablero Trello

Gestión del trabajo con Kanban (Backlog, Todo, In Progress, Review, Done).

Tablero DaySpend: https://trello.com/b/Ah33ouu1/dayspend

## Desarrollo local (frontend)

```bash
cd client
npm install
npm run dev
```

La consola mostrará una URL local (por ejemplo `http://localhost:5173/`).
